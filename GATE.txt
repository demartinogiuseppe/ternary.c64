TERNARY GATE - criterion decided BEFORE seeing any results

It passes if:
  1. ternary val loss <= fp32 val loss + 0.25
  2. at least 6 samples out of 10 form sentences that make sense

If B passes         -> continue with dim 64  (C64: 3-8 seconds per word)
If only C passes    -> continue with dim 128 (C64: 12-30 seconds per word)
If neither passes   -> the project is closed and the negative result published

Outcome: B failed (val loss 2.25 against 1.81). C passed at 1.4390. The
project continued at dim 128, and the third line was never needed.
